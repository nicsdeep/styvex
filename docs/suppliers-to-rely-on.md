# Suppliers to Rely On

This note records the approved supplier shortlist and sourcing rules for Styvex.

## Recommended API suppliers

### 1. Printful — primary recommendation

- Use for print-on-demand and branded apparel.
- Provides a documented REST API for products, variants, orders, shipping estimates, fulfillment status, and webhooks.
- No setup fee, order minimum, or required monthly subscription on the free plan.
- Styvex pays fulfillment costs only after a customer order has been placed.
- Confirm supplier fulfillment only after Styvex has verified successful customer payment.
- A merchant billing method is still required for fulfillment, and payment-processor payouts may arrive later than the supplier charge.
- Printful's API does not support jewelry.

### 2. Apliiq — secondary recommendation

- Use for branded apparel, embroidery, woven labels, and custom packaging.
- Provides product and order APIs.
- No setup or monthly dropshipping fee.
- Styvex pays only after a customer order has been placed.
- A saved credit or debit card is required before fulfillment can begin.
- A California reseller permit is optional; it is not required to open the account.
- Account for Apliiq's per-item fulfillment fee when calculating margins.

## CJ Dropshipping rule

- Continue considering CJ Dropshipping for ready-made fashion, bags, jewelry, and accessories.
- Only import or list a CJ product when the realistic Styvex retail price is **$30 USD or more**.
- This is a minimum retail-price threshold, not a supplier-cost threshold.
- Before listing, verify that product cost, current shipping cost, payment fees, returns exposure, and the intended margin still work at the chosen retail price.
- Do not send a fulfillment order to CJ until the customer's payment has been confirmed.

## Selection order

1. Use Printful when the product is suitable for print-on-demand apparel.
2. Use Apliiq when stronger private-label or apparel-branding features are needed.
3. Use CJ for suitable ready-made products that can credibly retail for at least $30.
